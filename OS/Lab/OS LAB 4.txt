Password Validation with Regular Expression
The Regular Expressionregex

^[a-zA-Z][a-zA-Z0-9_-]{0,7}$




1. write a regular expression for following pattern a password that should begin with an alphabet 
it should have max 8 charachters
alphabet can be followed by more alphabets or numbers or special charachters _  -  only 
Write a shell script to accept a password from user and check if it matches the above pattern using grep 
if match is found then print valid password else print invalid password

-----------------------------------

echo "Enter password: "
read password
echo ""

if echo "$password" | grep -Eq '^[a-zA-Z][a-zA-Z0-9_-]{0,7}$'; then
    echo "valid password"
else
    echo "invalid password"
fi

2. write a shell script that shows a menu 
		a. create directory
		b. check if directory is present
		c. remove directory
		d. show content of directory
		e. quit 
		
		accept a choice from user 
		   accept the full absolute path of the directory from user
		   and do as per choice 
		 Repeat till user enters choice e 
		 
		   
-----------------------------
while true
do
    echo "a. create directory"
    echo "b. check if directory is present"
    echo "c. remove directory"
    echo "d. show content of directory"
    echo "e. quit"
    
    read -p "Enter choice: " choice
    
    if [ "$choice" = "e" ]; then
        break
    fi

    if [[ ! "$choice" =~ ^[a-d]$ ]]; then
        echo "invalid choice"
        continue
    fi

    read -p "Enter full absolute path: " dir_path

    case $choice in
        a)
            if [ -d "$dir_path" ]; then
                echo "already exists"
            else
                mkdir -p "$dir_path"
            fi
            ;;
        b)
            if [ -d "$dir_path" ]; then
                echo "present"
            else
                echo "not present"
            fi
            ;;
        c)
            if [ -d "$dir_path" ]; then
                rm -rf "$dir_path"
            else
                echo "not found"
            fi
            ;;
        d)
            if [ -d "$dir_path" ]; then
                ls -la "$dir_path"
            else
                echo "not found"
            fi
            ;;
    esac
done
