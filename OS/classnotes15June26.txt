 what permissions can we give to a file ? 
  what does it mean ? 
 
   r w x  permissions to file 
    r = read permission = we can run cat , tac , vi command on file
    w = write permission = we can change file using vi and do :wq 
    x = execute permission = we can run the file on prompt of in					
			                   execl system call 
		   
	
    r w x permission to folder 
     r= read allowed = we can run ls , ls -R ,ls - l  etc on folder
     w = write allowed = we can mkdir,rmdir, rm -r, rm in the folder				 
						create a file in the folder using
							vi  or touch 
						cp a file in the folder
						mv move a file to the folder 
						mv rename the file in the folder 
	 x = we can cd to that folder

Segmentation = technique of non contiguous memory allocation by dividing 
process into segments 
on the basis of content
data structure = segment table = columns = segno , base,lengthlimit
registers = 
PC , MMU , STBR = segment table base register = address of seg table
STLR = holds the number of segments in the table = to verify if wrong seg number is not used
adv = external fragmentation is reduced, no internal fragmentation
		seg table is small
		
disav = ext frag not removed totally , segment table maintained

______________________________________________
Paging = technique of non contiguos memory allocation by dividing the process into
pages 

data structure = page table , page number frame number 

hardware of page table 
  = Page tables are HUGE = thousands of entries
    because the process is divided on the basis of size 
  = page tables are usually CACHED in TLB cache 
		Translation look aside buffer 
		It holds a part of page table of the current process
		
		
PTBR = Page table Base Register = address of Page table 


PC = holds page number and page offset of the next instruction 
MMU  will  
	check the TLB for the page number requested 
	if TLB cache HIT , GET the page number entry and find frame number 
	
	calculate actual address =  Frame number -base  + page offset 
	  of instruction 
	  
	If TLB cache MISS , GET the page table address from PTBR 
		and load the page table in TLB 
		find the frame number fro the page 
		
    calculate actual address =  Frame number -base  + page offset 
	  of instruction 
	  
	  
advantages of paging = External fragmentation is TOTALLY removed 
disadvantages = page table is very huge so additional overhead 
				to manage page table 
				Internal fragmentation may be there . 
	  
pages in the TLB that are frequently used are not removed 
		- improve HIT ratio	   
		- pages can have BITs associated with them 
			- dirty bit or change bits = 
				they tell whether a page is changed or not

Demand Paging / Virtual Memory 


The full process is NOT loaded in RAM = Partial process is loaded in RAM 
In Non contiguous memory locations 

Non contiguous memory location = prevents external fragmentation
no loading the full process in RAM = 
			1. per process less RAM pages are needed = 
				degree of multiprogramming improves 
			= increases the number of processes that LTS can be loaded
				in the RAM at a time 

			degree of multiprogramming = how many processes
								can be in the RAM at a time


			2. loader job is reduced = only the required pages will loaded 
				unneccessary loading is avoided 
				
			3. Programmer can write code bigger than RAM size 
	
___________________________________________
Remaining pages that are not loaded in the RAM are placed in 
SWAP SPACE ( part of the HDD/SSD )	
SWAP SPACE  = Virtual Memory

Technique = 
	User wants to run a program 
	LTS loads 30 pages of the process in RAM out of 100 pages 
		a page table of 30 entries is created 
		 30 pages get frames 
		 
	Remaining 70 pages are on the swap space 
	
	Process starts execution after it gets the CPU 
		one by one instructions are loaded in IR , executed by ALU 
		and next instruction address is loaded in PC 
	            this address has page number and page offset 
		MMU = refers to the page table in TLB 
				PTLR = check if page number is in the page table 
				If the page number is in the Page table 
				FIND the frame number 
					Frame-base + page offset 
	
	
	Let us say 30 pages are in the page table 
	
	PC Demands  page 10 , offset 70 
	page 10 is in the page table  - HIT = the instruction loaded in CPU
	
	Next PC demands page 45 , offset 33 
	PTLR = says that page is not in the RAM 
	     = Page Fault Interrupt occurs 
		 = Interrupt handler RUNS = Puts the current process in 
				IO wait state 
		     load the DEMANDED page from SWAP SPACE to free frame in RAM 
			 update the page table 
			 move the FAULTING proces from WAIT state to ready  state 
			 
	     If No free frame is available  ??? 
			Page fault occurs ??? 
			Kernel will now SWAP the current page in frame with the
			demanded  page
			Kernel performs Page Replacement !!!
