System = basic computer organization 

 SSD/HDD  = secondary storage
 RAM /Memory = primary memory - exe is loaded
 CPU 
   Registers - small size fast access storage devices ( at a time they can hold only one value ) 
   different registers -
		IR = Instruction Register 
		DR0 = data register 0
		DR1 = data register1 
		
		sum = x + y 
		IR = +
		DR0 = value of x
		DR1 = value of y
		
		IR ==>
		DR0 ==>   ALU( Arithmetic and Logic ) 
		DR1 ==>  
		
		After ALU circuit executes the instruction the result is stored in one more register = Accumulator 
   
        From Accumulator the output is saved to cache or RAM 
		
		PC = Program counter = It stores the address of the next instruction
   
		ALU = Arithmetic and logic unit 
		Which instructions can it execute?
             arithmetic instr = + - * / % 
			 logic instr = && || ! 
			 relational instr = < > <=>= != ==
		All the above are called as 
		CPU instructions
