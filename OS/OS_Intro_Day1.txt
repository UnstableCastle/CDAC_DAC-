=================================================
            OPERATING SYSTEM (OS)
=================================================

1. SOFTWARE AND PROGRAMS
-------------------------------------------------

Program
- A set of instructions given to a computer system.

Software
- A collection of programs designed to solve a problem.

Example:
- Calculator
- Browser
- MS Word
- WhatsApp

=================================================
2. TYPES OF SOFTWARE
=================================================

A. System Software
------------------
Software used to manage and operate the system.

Examples:
- Operating System (OS)
- Device Drivers
- Compiler
- Interpreter
- Loader
- Linker

B. Application Software
------------------------
Software developed to solve user problems.

Examples:
- Calculator
- Media Player
- Browser
- Notepad
- PowerPoint
- WhatsApp
- Canva
- Instagram
- Excel
- Google Maps
- Google Pay
- LLMs (ChatGPT, Grok)

=================================================
3. COMPILER
=================================================

Definition:
- Converts source code from one language into another.

Example 1:
Source (.c/.cpp)
      |
      v
     GCC
      |
      v
Machine Language

Example 2:
Source (.java)
      |
      v
    javac
      |
      v
Bytecode (.class)

=================================================
4. INTERPRETER
=================================================

Definition:
- Translates one line at a time.
- Executes immediately.
- Repeats until program ends.

Important:
- NEVER produces an output file.

Examples:

.py  ---> Python Interpreter

.js  ---> Node.js Interpreter

.class ---> JVM (Java Interpreter)

=================================================
5. LOADER
=================================================

Definition:
- Loads executable files from secondary storage
  (SSD/HDD) into RAM.

Examples:

Class Loader:
.class --> RAM

GRUB Loader:
Boot program --> RAM

=================================================
6. LINKER
=================================================

Definition:
- Converts offset addresses into actual addresses.

9. SYSTEM CALLS
=================================================

Application Program:

add.c

main()
{
    printf("Enter numbers");
    scanf(...);
    sum = x + y;
    printf(sum);
}

OS View:

write() system call
read() system call
sum = x + y
write() system call

Definition:
- A system call requests services from OS.

Kernel:
- Core part of Operating System.
- Executes system calls.

=================================================
11. PROGRAM EXECUTION FLOW
=================================================

Step 1:
Write add.c using keyboard.

Step 2:
Store add.c in SSD/HDD.

Step 3:
Compiler generates add.exe.

Step 4:
Loader loads add.exe into RAM.

Step 5:
CPU executes instructions.

Step 6:
Results stored in RAM.

=================================================
13. CPU ARCHITECTURE
=================================================

CPU contains Registers.

Registers:
- Very small
- Very fast
- Hold one value at a time

Important Registers:

1. IR (Instruction Register)
2. DR0 (Data Register 0)
3. DR1 (Data Register 1)
4. PC (Program Counter)
5. Accumulator

Example:

sum = x + y

IR  = +
DR0 = x
DR1 = y

        IR
         |
DR0 --> ALU <-- DR1
         |
         v
    Accumulator

=================================================
14. ALU (Arithmetic Logic Unit)
=================================================

Executes CPU Instructions.

Arithmetic:
- +
- -
- *
- /
- %

Logical:
- &&
- ||
- !

Relational:
- <
- >
- <=
- >=
- ==
- !=

=================================================
15. DMA CONTROLLER
=================================================

DMA = Direct Memory Access

Purpose:
- Performs I/O operations.
- Can transfer data without CPU involvement.

Functions:
- Device -> RAM
- RAM -> Device

=================================================
16. TYPES OF INSTRUCTIONS
=================================================

CPU Instructions
----------------
Executed by ALU.

Examples:
- Arithmetic
- Logical
- Relational

I/O Instructions
----------------
Executed by DMA Controller.

26. BASIC LINUX COMMANDS
=================================================

1. pwd
-------
Print current directory.

Example:
$ pwd

-------------------------------------------------

2. cd
------
Change directory.

Examples:

$ cd /

-------------------------------------------------

3. ls
------
List directory contents.

Example:

$ ls

-------------------------------------------------

4. mkdir
---------
Create directory.

Example:

$ mkdir /home/yourlogin/OS

-------------------------------------------------

5. Clear Screen
---------------
